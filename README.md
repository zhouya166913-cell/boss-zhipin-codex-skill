# BOSS 直聘 Codex Skill

一个面向 Codex 的 BOSS 直聘连接与操作 Skill，重点支持招聘方查看岗位、搜索候选人、阅读简历、处理沟通和面试邀约。项目使用隔离运行时和显式写操作确认，避免误发消息或意外修改岗位。

> 非 BOSS 直聘官方项目。BOSS 直聘没有面向公众的通用招聘开放 API。本项目依赖社区维护的 `jackwener/boss-cli` 锁定源码提交和用户本人的登录态，使用前请评估平台协议、账号风控和候选人隐私要求。

## 交给 Codex 安装

将下面这句话发给 Codex：

```text
请安装并使用这个 Skill：https://github.com/zhouya166913-cell/boss-zhipin-codex-skill
先检查环境和登录状态，只执行只读检查，不要发送消息或批量操作。
```

也可以手动安装：

```text
npx skills add https://github.com/zhouya166913-cell/boss-zhipin-codex-skill -y -g
```

安装 Skill 后，首次使用时 Codex 会：

1. 检查 Python 3.10+；
2. 在用户目录创建隔离虚拟环境；
3. 安装固定版本的 BOSS CLI 执行依赖；
4. 引导用户本人扫码或使用本机浏览器登录；
5. 先验证登录和只读能力；
6. 仅在用户明确确认后执行消息、邀约、岗位修改和数据导出。

## 能力范围

招聘端：

- 查看已发布岗位；
- 搜索和查看推荐候选人；
- 查看候选人资料、简历和聊天记录；
- 生成人工审核后的沟通内容；
- 经确认后回复、索要简历或联系方式、邀约面试；
- 经确认后上下线岗位、标记不合适或导出候选人。

求职端：

- 搜索、筛选和查看职位；
- 查看推荐、投递和面试记录；
- 经确认后向招聘者打招呼。

## 本地自检

```text
python -m unittest discover -s tests -v
python scripts/bootstrap.py check
```

测试不会登录 BOSS，也不会访问候选人数据。真实连接需要用户本人登录，并且可能因平台接口变化而失效。

## 安全边界

- 不提交或展示 Cookie、Token 和浏览器凭证；
- 不绕过验证码、访问频率限制或平台风控；
- 不默认执行批量打招呼、自动回复或批量下载简历；
- 所有远程写操作需要即时、明确的用户确认；
- 批量操作必须先预览并再次确认；
- 候选人信息和导出文件不得上传到公开仓库。
